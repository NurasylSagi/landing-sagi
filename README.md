# Kazakhstan Travel

Лендинг о туристических местах Казахстана.

## О проекте

Сайт показывает популярные туристические направления Казахстана:

- Чарынский каньон
- Кольсайские озёра
- Горы Алматы

На сайте есть навигация, карточки туристических направлений и контактная форма.

## Использованный инструмент

### Bootstrap 5

В проекте используется Bootstrap 5 для создания адаптивного интерфейса.

Bootstrap выбран потому, что он позволяет быстро создавать адаптивную структуру сайта с готовыми компонентами.

В проекте используются:

- `container` — ограничивает ширину содержимого;
- `row` — создаёт строку сетки;
- `col-12 col-md-6 col-lg-4` — делает карточки адаптивными;
- `navbar` — навигационная панель;
- `card` — карточки туристических направлений;
- Bootstrap buttons и forms;
- Bootstrap CSS-переменные.

## Адаптивность

Сайт рассчитан на следующие размеры экранов:

- 375 px — мобильный телефон;
- 768 px — планшет;
- 1280 px — компьютер.
